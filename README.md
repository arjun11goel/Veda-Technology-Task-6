# Veda-Technology-Task-6
# Text Analysis - AI & ML Track

## Description
This project demonstrates a foundational Natural Language Processing (NLP) text analysis tool built using Python in a Jupyter Notebook. It analyzes a given sample text to calculate the total number of words, characters, vowels, and identifies repeated words.

## Objective
The main objective of this task is to practice basic text processing techniques that are essential for Natural Language Processing.

## Tools & Technologies
* **Python**
* **Jupyter Notebook**

## Features & Deliverables
* **Word and Character Counts:** Calculates total characters (using `len()`) and total words (using `.split()`).
* **Vowel Analysis:** Iterates through the text to count the occurrences of vowels (A, E, I, O, U).
* **Repeated-Word Analysis:** Preprocesses the text (lowercasing and removing punctuation) and uses Python's `collections.Counter` to identify and count words that appear more than once.

## How to Run
1. Ensure you have Python and Jupyter Notebook installed on your system.
2. Open the Jupyter Notebook containing the project code.
3. Run the cells sequentially from top to bottom.
4. **Customization:** You can easily change the `text` variable in the initial code cell to analyze your own custom paragraph, a news article, or any other text dataset.
